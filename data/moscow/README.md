# Карта Москвы: формат данных и инструменты

## Файлы

- `schema.json`: JSON-схема точки. Обязательные поля: id, category, name, address, district, lat, lon, source, checked_at. Необязательные: phone, hours, site, price.
- `validate.mjs`: проверка JSON файла. Запуск: `node data/moscow/validate.mjs <файл.json>`.
- `import-csv.mjs`: импорт CSV в JSON. Запуск: `node data/moscow/import-csv.mjs <in.csv> <out.json>`. Первая строка заголовок с именами полей.
- `examples/`: пример валидной точки и битого файла для проверки валидатора.

## Правила проверки

Категория только из списка: vet, boarding, grooming, park, shelter, shop. Координаты в границах Москвы с запасом: широта 55.10-56.10, долгота 36.70-38.50. Границы заданы решением проекта, покрывают Москву в административных границах. Дубли ищутся по паре адрес плюс название после нормализации регистра и пробелов, а также по id. Поле checked_at в формате YYYY-MM-DD. Поля source и site должны быть URL вида http(s).

## Источники данных

Фактические точки вносятся только со ссылкой на источник в поле source. Нет источника: запись не вносится. Телефоны, адреса и координаты берутся из источника, не выдумываются.
