# Доска потеряшек: тестовые данные

Файл `board.json` — его читает страница `/lost`. Копия того же набора лежит в `sample.json`.
Сейчас в обоих файлах только демонстрационные объявления. Все телефоны, адреса и имена вымышлены, помечены полем `test: true`. Не использовать как реальные данные.

Поля: id, kind (lost/found), animal (dog/cat/other), name (может отсутствовать у найденных), district (округ), place (общественное место без точного адреса дома), date (YYYY-MM-DD), contact, description, test.
