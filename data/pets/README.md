# Публичные профили питомцев: тестовые данные

Файл `sample.json`: тестовые профили для вёрстки страницы `/p/{slug}`. Имена и данные вымышлены, записи помечены `test: true`. Фото отсутствует, карточка показывает заглушку с инициалом.

Поля: slug, name, species (dog/cat/other), breed, age, verified (галочка), photo (пока null).
