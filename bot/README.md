# Бот «Моя стая»: MVP напоминаний

Телеграм-бот для напоминаний о прививках, таблетках и визитах. Хранение в FamilyOS API, отправка по расписанию.

## Состав

- `bot.py`: длинный опрос Telegram, диалоги /start, /addpet, /pets, /remind, /list, /cancel.
- `check_due.py`: отправка наступивших напоминаний. Крон каждые 5 минут.
- `bot/config.py`: конфиг из окружения.
- `bot/clients.py`: клиенты Telegram Bot API и FamilyOS API, только стандартная библиотека.
- `bot/store.py`: питомцы и напоминания в заметках инвентаря FamilyOS.
- `bot/dialog.py`: логика диалога без сети, покрыта тестами.
- `test_dialog.py`: `python3 -m unittest test_dialog`.

## Хранение

Выделенных endpoints питомцев и напоминаний в FamilyOS API нет, факт по swagger.json. Заметки инвентаря используются как key-value хранилище, префикс `myastaya:`. Это решение проекта для MVP. Нужен ключ API со скоупом inventory, выдаёт владелец.

## Запуск

Переменные окружения: `TELEGRAM_BOT_TOKEN`, `FAMILYOS_API_URL`, `FAMILYOS_API_KEY`. Пример в `.env.example`. Секреты в репозиторий не кладутся.

Локально: `TELEGRAM_BOT_TOKEN=... FAMILYOS_API_URL=... FAMILYOS_API_KEY=... python3 bot.py`. Крон: `*/5 * * * * /usr/bin/python3 /opt/staya-bot/check_due.py` с теми же переменными в окружении крона.

Проверено 01.11.2026: юнит-тесты диалогов 4/4, сквозной прогон против заглушки Telegram и живого локального FamilyOS (регистрация, питомец, напоминание, список, отправка по крону, пометка sent), тестовые записи и ключ удалены.

## Ограничения MVP

Состояние диалога в памяти процесса, рестарт его сбрасывает. Один процесс опроса. Часовой пояс Europe/Moscow по умолчанию. Живой диалог в Telegram требует токена от BotFather, выдаёт владелец.
