# PetFamily

Веб-сервис для владельцев собак: профиль питомца, прогулки, карта, встречи рядом.

Монорепозиторий:

- `apps/api` — HTTP API на Go
- `apps/admin` — админка (отдельный сервис, отдельный под)
- `apps/web` — фронт на Vite + React

Первая волна: регистрация, питомцы, прогулки, история маршрутов, встречи. Захват территории, античит и трансляции не входят.

Запуск тестов:

```
cd apps/api && go test ./...
```

Локальный стенд поднимается через `docker compose up --build` (появится вместе с API и базой).
