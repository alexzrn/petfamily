# petfamily — «Моя стая»

Портал для владельцев собак и кошек в Москве: карта проверенных мест, карточки точек и доска потеряшек. Не лендинг:
на первом экране — поиск, категории и карта.

- Стек: Astro 7, Node >= 22.23.4
- Сборка: `npm ci && npm run build` → `dist`
- Хостинг: Cloudflare Pages (проект `petfamily`, домен `petfamily.beliberde.net` через nginx)
- Бэкенд: FamilyOS API (`https://familyos.beliberde.net/api/v1`) — используется ботом, не страницами
- Деплой: пуш в `main` → автосборка и публикация

## Страницы

| Адрес | Что там |
| --- | --- |
| `/` | Портал: поиск по названию и адресу, переключатель категорий, карта Москвы с точками, счётчик точек, переходы в карту, потеряшки и бота |
| `/map` | Карта на Leaflet (тайлы OpenStreetMap) с фильтрами по категории и признакам «круглосуточно», «выезд», «стационар», поиском и списком рядом (на мобильном — под картой) |
| `/spot/{id}` | Карточка точки: название, адрес, телефон, часы, сайт, источник, дата проверки, координаты, кнопка «Позвонить» и переход на карту |
| `/lost` | Доска потеряшек: фильтры по типу, виду животного и округу, форма «сообщить» с клиентской проверкой |
| `/bot` | Что умеет Telegram-бот напоминаний, команды и статус запуска |

Старые адреса не ломаются: `/map` и `/lost` отдают свои страницы, а не главную.

## Данные

- `data/moscow/spots.json` — 113 точек Москвы (клиники, площадки, приюты, передержка, груминг, магазины) с координатами, источником и датой проверки. Формат и инструменты — в `data/moscow/README.md`.
- `data/lost/board.json` — объявления доски потеряшек (сейчас демонстрационные, `test: true`).
- `data/pets/sample.json` — тестовые профили питомцев.
- `bot/` — код Telegram-бота напоминаний (запуск требует токена, см. `bot/README.md`).

## Структура

- `src/layouts/Base.astro` — общий каркас: шапка с навигацией, подвал с пояснением об источниках.
- `src/lib/portal.ts` — загрузка точек, подписи категорий, счётчики, приведение телефона к `tel:`.
- `src/pages/` — страницы портала.
- `public/portal.js` — карта, фильтры, поиск, список результатов.
- `public/lost.js` — фильтры доски и форма с проверкой полей.
- `public/vendor/leaflet/` — Leaflet 1.9.4 локально, без CDN и внешних скриптов.
- `src/styles/global.css` — стили, один акцентный цвет, мобильная колонка.

Внешних скриптов и аналитики нет: Leaflet лежит в репозитории, из сети грузятся только тайлы OpenStreetMap.

## Сборка страниц без слеша

`astro.config.mjs` собирает страницы как `map.html`, `spot/vet-001.html` (`build.format: 'file'`), чтобы Cloudflare Pages
отдавал `/map` и `/spot/vet-001` сразу с кодом 200, без редиректа на слеш. `public/_redirects` дублирует это правило
как rewrite.

## Проверка данных

```bash
node data/moscow/validate.mjs data/moscow/spots.json
```

Валидатор проверяет обязательные поля, категории, границы Москвы, формат даты и URL, дубли по `id` и по паре
«адрес + название».

## Разово: статический каркас

Файлы `index.html`, `app.js`, `styles.css` в корне — старый статический каркас, сборка Astro их не использует: в `dist`
попадает только `src/` и `public/`.
